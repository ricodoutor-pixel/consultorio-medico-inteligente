## 🚀 INSTRUÇÕES DE DEPLOY

### Passo 1: Sincronizar com GitHub
```bash
cd /home/ubuntu/consultorio-medico-inteligente
git pull origin main
```

### Passo 2: Instalar Dependências
```bash
pnpm install
```

### Passo 3: Executar Testes
```bash
pnpm test
```

### Passo 4: Build
```bash
pnpm build
```

### Passo 5: Deploy em Hostinger
```bash
# SSH para servidor
ssh seu_usuario@seu_servidor.hostinger.com

# Sincronizar código
cd consultorio-medico-inteligente
git pull origin main

# Instalar e testar
pnpm install
pnpm test

# Build
pnpm build

# Reiniciar
pm2 restart planta-raiz-app
pm2 save
```

### Passo 6: Validar
```bash
curl https://plantayraiz.com.br/health
```
